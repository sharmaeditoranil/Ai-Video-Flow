AI Video Flow - Install Guide
=============================

MAC (Apple Silicon M1/M2/M3/M4 or Intel - use the matching DMG)
  1. Drag "AI Video Flow" into the Applications folder.
  2. Open Applications and double-click AI Video Flow.
  3. If macOS says it cannot verify the app:
       System Settings -> Privacy & Security -> scroll down -> "Open Anyway" -> Open.
     (Only needed the first time.)

WINDOWS 10 / 11
  1. Run AI-Video-Flow-Windows-Setup.exe.
  2. If Windows shows "Windows protected your PC": click "More info" -> "Run anyway".
  3. Open "AI Video Flow" from the Desktop or Start Menu.

FIRST USE
  - The free plan works right away (1 project per day, no internet needed).
  - DaVinci Resolve: Preferences -> System -> General ->
    "External scripting using" = Local -> Save -> restart Resolve.
  - Premiere Pro and EDIUS: timelines are saved as XML in the "AI-Video-Flow-Output"
    folder in your home folder (AI Studio -> Output folder).
  - Bought a plan? Open "My Profile", paste your license key and press Activate.
  - Plans: open "Pricing" inside the app.
